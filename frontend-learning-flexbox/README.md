# Frontend Learning - HTML, CSS & JavaScript

This project contains the class learning problems implemented in plain HTML, CSS and JavaScript.

## Completed

1. HTML Introduction + Web Page Layout
2. Flexbox Website Layout 1
3. Flexbox Photo Gallery - row + wrap
4. Flexbox Card Layout - align-items: stretch
5. Flexbox Media Object Layout
6. Basic JavaScript interaction

## Run in VS Code

### Option 1 - Live Server

1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Test every navigation link.

### Option 2 - VS Code terminal

If Python is installed:

```bash
python -m http.server 5500
```

Then open:

```text
http://localhost:5500
```
