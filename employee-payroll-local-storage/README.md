# Employee Payroll App (Local Storage)

This folder contains a complete Employee Payroll application built with HTML, CSS, and JavaScript. It supports create, update, read, and delete (CRUD) operations, and stores employee records in browser localStorage.

## Features

- Add new employees with name, employee ID, department, and salary.
- Edit existing employee records.
- Delete employee records.
- Search employees by name, ID, or department.
- View summary counts and total payroll value.
- Persist data across page refreshes using localStorage.

## Files

- `index.html` — app user interface and markup.
- `css/style.css` — responsive design and page styling.
- `js/script.js` — form validation, localStorage persistence, CRUD behavior.

## Run the app

1. Open the folder in VS Code.
2. Open `index.html` in the browser or use a Live Server extension.
3. Add and manage employee records.

## Notes

- The app stores data only in the browser where it is opened.
- Clearing the browser storage or using a different browser will reset the records.
