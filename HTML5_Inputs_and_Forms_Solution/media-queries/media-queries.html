1. Anatomy of a Media Query

@media screen and (min-width: 600px) { /* CSS rules */ }

  • AT RULE – @media starts every media query.
  • MEDIA TYPE – screen, print, speech, all...
  • MEDIA FEATURE – e.g. min-width, max-width, orientation.
  • OPERATORS – and, or (comma separated), not.
